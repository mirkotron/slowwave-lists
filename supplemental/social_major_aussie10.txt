# SlowWave supplemental list: Major social media platforms
#
# This is the Australian "Aussie 10" list (Online Safety Amendment, effective
# Dec 10 2025) - the narrowest defensible "block social" set for tier 5
# (16-17yo) since it has explicit legal precedent.
#
# For younger tiers (0-15), use this list UNIONED with StevenBlack's social
# extension via the policy file - StevenBlack covers broader social (forums,
# smaller networks, etc.) which is appropriate for younger kids.
#
# Australian regulator explicitly EXEMPTED: Discord, GitHub, Google Classroom,
# Messenger, Pinterest, Roblox, Steam, WhatsApp, YouTube Kids. These are NOT
# in this list. Add them per-tier in policy.yaml if desired.
#
# Last reviewed: 2026-05
