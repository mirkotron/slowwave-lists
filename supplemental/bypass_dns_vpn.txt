# SlowWave supplemental list: DNS-bypass and VPN/proxy escape vectors
#
# CRITICAL FOR SLOWWAVE: A kid who can change device DNS to 1.1.1.1, install
# ProtonVPN, or run Tor defeats the entire SlowWave filter. This list is the
# "filter integrity" layer - it MUST be on for all minor tiers and SHOULD be
# non-overridable from the SlowWave UI without re-PIN.
#
# This supplements HaGeZi's doh.vpn.proxy.bypass list (which is more
# comprehensive). Use both, unioned.
#
# Strategy:
#   1. Block DoH/DoT endpoint domains at DNS layer (this file)
#   2. Block known DoH/DoT IPs at iptables layer (separate, see ip_blocklist)
#   3. Force port 53 traffic through SlowWave's dnsmasq via iptables redirect
#   4. Block all UDP/853 (DoT) and TCP/853 outbound
#   5. Drop SNI matching known DoH hostnames at TLS-inspection layer (optional)
#
# Last reviewed: 2026-05
